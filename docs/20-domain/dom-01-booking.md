# 予約

> **サンプルノード。** 実プロジェクトでは差し替えること。

## 定義

利用者が、ある資源をある時間帯について確保した記録。確保されている間、
同じ資源の同じ時間帯は他の利用者が確保できない。

## 属性

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 識別子 | ○ | 予約を一意に識別する |
| 利用者 | 識別子 | ○ | 予約を保持する主体 |
| 資源 | 識別子 | ○ | 確保の対象 |
| 時間帯 | 開始 / 終了 | ○ | 開始 < 終了。分単位 |
| 状態 | 列挙 | ○ | 仮予約 / 確定 / 取消 |

## 不変条件

- [ ] 開始時刻は終了時刻より前である
- [ ] 同じ資源に対して、時間帯が重なる「確定」状態の予約は存在しない
- [ ] 「取消」になった予約は、以後どの属性も変化しない

## ライフサイクル

```
仮予約 ──確定──▶ 確定 ──取消──▶ 取消
   └────取消─────────────────────┘
```

「仮予約」は保持期限を持ち、期限を過ぎたものは自動的に「取消」になる。

## 用語

| 用語 | 意味 | 使ってはいけない言い換え |
| --- | --- | --- |
| 資源 | 確保の対象となるもの | 部屋、席、枠（実体に引きずられる） |
| 確定 | 重なりの排除が保証された状態 | 承認、登録完了 |
